Overview

This project involves building a smart robot using TI TMS320F28379D and an ESP32 module. It uses PID control for line tracking and supports wireless tuning of motor speed and other parameters via WiFi and UART, enabling fine-grained control and real-time system optimization during operation. The design focused on responsiveness, reliability, and ease of tuning.

Concept

To build a responsive and tunable robot, the project included the following features:

  • PID-based motor control for accurate and smooth line tracking in real time.
  • Live parameter tuning via UART over WiFi using ESP32 integration.
  • Multithreaded real-time scheduling with SYS/BIOS RTOS, utilizing HWI, SWI, and Idle threads.
  • Feedback loop to monitor and report RPM, motor power, and tracking performance to the user interface.

Achievements

  • Designed and tuned a responsive PID controller through iterative real-world testing.
  • Implemented safety protocols (e.g., divide-by-zero guards) to ensure robust, fault-tolerant operation.
  • Integrated real-time UART communication with the ESP32 for wireless updates to control parameters.
  • Used SYS/BIOS to allocate system tasks efficiently, balancing CPU usage.
  • Developed a simple monitoring interface that displays real-time speed and power data.

Outcome

Success! The robot followed a black line track with adjustable speed and PID gains, while wirelessly reporting motor data and system status.
